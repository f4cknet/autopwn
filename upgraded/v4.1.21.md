## 1. 背景

`v4.1.20` 已把新任务详情拆到 `upgraded/vX.Y.Z.md`，但主索引 `upgraded.md` 仍然偏大：

- 历史长任务行仍然占据主表
- v4.0 详细状态说明仍留在主文档
- 文件路径 / 模板 / 工具速查仍放在主文档附录

这让 `upgraded.md` 还没有真正收敛成“只读当前、快速进入状态”的索引页。

## 2. 目标

进一步把 `upgraded.md` 瘦身为**主索引**：

- 只保留阅读入口、流程、当前活动任务、待收尾任务、最近完成任务、验证基线
- 历史未完成 backlog、旧状态长说明、附录速查全部下沉到 `upgraded/`
- AI Agent 非追溯场景默认不读历史归档，减少 session 启动成本

## 3. 范围

**范围**：`AGENTS.md`、`upgraded.md`、`upgraded/backlog.md`、`upgraded/archive_completed.md`、`upgraded/archive_state.md`、`upgraded/appendix.md`。

**非目标**：
- 不改任务 ID / 状态机 / 6 关验收
- 不顺手改 `refactor.md` / `rebuild.md`
- 不把 backlog 历史任务一次性都拆成独立 `vX.Y.Z.md`，只要求“重新开工前先拆出详情文件并回填主索引”

## 4. 新规则

1. `upgraded.md` 只保留**当前活动任务**、**待收尾任务**、最近完成任务和历史入口链接
2. 历史 backlog 统一收纳到 `upgraded/backlog.md`；如果其中某项重新实施，必须先回填到 `upgraded.md §3`，再拆出 `upgraded/vX.Y.Z.md`
3. 文件路径、工具脚本、模板、决策表迁到 `upgraded/appendix.md`
4. v4.1.21 前的详细状态长说明迁到 `upgraded/archive_state.md`
5. AI Agent 非追溯场景默认不读 `backlog.md` / `archive_*.md`，只有做历史任务或审计时才进入这些文件
