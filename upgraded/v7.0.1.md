# v7.0.1 交互层：`Plan.sends` → `Plan.steps`（`Send` / `Wait`）

- **索引位置**：`upgraded.md §2`
- **状态**：✅
- **Owner**：@Minzhi_Zhou
- **预估 / 实际**：4h / 2h

## 1. 背景

当前 `Plan` 只携带 `sends: list[bytes]`，交互语义全部丢失：

- `run.execute` 只能在相邻 blob 之间用「读到静默」隐式同步，无法表达「等某个 prompt 再发」；
- `_try_ret2libc` 只发 `plan.sends[-1]`，会把 `_presets()` 生成的 scanf 前置输入静默丢弃（真实 bug）；
- 菜单前缀 `b"w\n"` 与 payload 混在同一个 bytes 列表里，失败时无法说明卡在哪个交互阶段；
- 时序偏好在 `execute` / `execute_flag` / `_try_*` 里各写一份，`ch08` 偶发抖动即来源于此。

本版只做 `upgraded/v7.0.0.md` 四层提案中的 **L1 交互层**，不改 `facts.py`（当前没有 prompt 字符串事实）。

## 2. 目标

1. `Plan` 携带步骤序列 `Send` / `Wait`，旧 `list[bytes]` 写法继续可用；
2. 收发时序只有一份实现（`interact.Interaction.run_steps`），三处调用方复用；
3. 修复 `_try_ret2libc` 丢弃前置步骤的真实 bug；
4. 给后续「facts 输出 prompt → 策略自动 `Wait(prompt)`」铺路。

## 3. 范围

**做：**

- 新增 `autopwn/engine/interact.py`：`Send` / `Wait` / `normalize_steps` / `Interaction` / `StepError` / `WaitTimeout`
- `strategies.Plan(strategy, steps, desc, tag)`，`__post_init__` 归一化，保留 `sends` / `last_send` 兼容属性
- `run.execute` / `run.execute_flag` 改用 `Interaction.run_steps`，删除 `_sync`
- `s_ret2win` / `s_ret2win_flag` 在菜单前缀后插入 `Wait()`
- `orchestrator` 三处分派改传 `plan.steps`；`_try_ret2libc` 重放完整步骤
- 独立回归脚本 `scripts/test/interaction_vector.py`（FakeTube + 真实 C 菜单程序）

**不做：**

- 不改 `facts.py`，不提取 prompt 字符串（留到 v7.1）
- 不统一 Oracle（v7.0.2）、不迁移 `_try_canary_fmt` / `_try_pie_partial`（payload 含运行时地址）
- 不新增 bench 题、不改基线分母、不加 pytest 依赖
- 不新增堆 / SROP / ORW 策略，不调参

## 4. 设计要点

| 项 | 约定 |
|---|---|
| `Wait(needle=b"")` | 读到静默（旧 `_sync` 语义），随后把游标推到缓冲末尾 |
| `Wait(needle)` | 从游标起在**累积缓冲**中查找，默认超时 `_verify_timeout(ch)`（本地 2.2s / 远程 6s） |
| Send → Send | `execute` / `_try_ret2libc` 走 `drain`（0.06s 轮询 / 1.0s deadline）；`execute_flag` 走 `send_gap=(0.15, 0.05)` |
| Send → Wait | 不自动读，Wait 独占该边界 |
| 最后一步之后 | `execute`: 0.2 + 0.04；flag: 0.15 + 0.05；ret2libc: 0.25 + 0.25 |
| 错误 | `StepError.partial` = 失败时的完整累积输出；调用方直接作为 `Result.output`，不重复累加 |
| 兼容 | `Plan("x", [b"..."])` 全部无需改；空 `bytes` 归一化时丢弃 |

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 时序漂移影响 13/15 基线 | 逐项复刻旧常量；先跑关键单题再跑全量 |
| 空菜单也加 Wait 导致每 plan +1s | 只在菜单前缀非空时插入 |
| Wait 匹配到旧 prompt | 静默 Wait / 隐式同步后推进游标；局限写入文档 |
| ret2libc 前缀修复改变 scanf 题尝试序列 | 观察 attempts，必要时让空 preset 先试 |
| 远程 RTT 导致 Wait 超时过短 | 远程默认 6s，显式 `timeout=` 可覆盖 |
