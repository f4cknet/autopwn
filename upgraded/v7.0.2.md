# v7.0.2 L3 判定统一：`Oracle`（`Shell` / `Flag` / `File`）+ `cause`

- **索引位置**：`upgraded.md §2`
- **状态**：✅
- **Owner**：@Minzhi_Zhou
- **预估 / 实际**：3h / 1.5h

## 1. 背景

成功判定现在有 **4 份实现**，口径靠人肉对齐，历史上 2 个 bug 都出自这里：

| 位置 | 判定 | 问题 |
|---|---|---|
| `run.verify_shell` | `MARKER in out or re.search(uid=\d+)` | 基准实现，但无 cause |
| `run.probe_flag` | `FLAG_RE.search(out)` | 只看自己窗口（execute_flag 已兜累积） |
| `run.execute_flag` | `FLAG_RE.search(blob)` + `No such file...` → `win reached` | 第 2 份 flag 正则 + 内联 File 判定 |
| `orchestrator._try_pie_partial` | 内联第三份 `FLAG_RE` 正则 + `No such file or cat: ` | 修正则一改就要改三处 |

具体踩过的坑（`bench/RESULTS.md §9`）：`probe_flag` 只看新数据 → 早到的 flag 被判负；
`No such file` 是「链路通了」的证据却被当成失败 → 后来加了 `win reached`，又是各写一份。

## 2. 目标

1. 判定收敛到一个模块 `autopwn/engine/oracle.py`：判定只有这一份；
2. 失败/成功都带 **`cause`**（机器可读的归类），为 L4 失败归因铺路；
3. `FLAG_RE` / `NO_FILE_RE` 常量唯一化，`run.py` 从 oracle 导入；
4. 不改判定语义本身——只合并位置，回归数字必须纹丝不动。

## 3. 范围

**做：**

- 新增 `oracle.py`：`FLAG_RE` / `NO_FILE_RE` / `SHELL_MARKERS` / `judge_shell()` / `judge_flag()` / `Verdict`
- `run.py`：`verify_shell` / `probe_flag` / `execute_flag` 的判定行改为调 oracle；
  `Result` 增加 `cause: str` 字段；`FLAG_RE` 保留为 `from .oracle import FLAG_RE` 的转发（orchestrator 在用）
- `orchestrator.py`：`_try_pie_partial` 的两处内联判定换成 `judge_flag`；
  `Attempt.brief()` / `SolveResult.as_dict()` 带 `cause`
- `scripts/test/interaction_vector.py` 增加 oracle 单元检查（真进程与 FakeTube 都不需要，纯函数）

**不做：**

- 不改判定语义（正则、MARKER、优先级、`win reached` 口径全部原样）
- 不动 `_try_ret2libc` / `_try_canary_fmt` 的链条逻辑
- 不动 facts / strategies
- 不新增 bench 题（判定单元检查走独立向量脚本）

## 4. 设计

```python
@dataclass
class Verdict:
    ok: bool
    kind: str        # "shell" | "flag" | "file" | "none"
    cause: str       # "marker" | "uid=" | "flag_re" | "no_flag_file" | "no_match"
    detail: str      # 命中的 flag / uid 串，供 note 拼接

FLAG_RE     = re.compile(rb"(?:flag|ctf|FLAG|CTF)[A-Za-z0-9_]{0,20}\{[^}\n]{4,}\}")
NO_FILE_RE  = re.compile(rb"No such file|Permission denied|unavailable|cat: ")
SHELL_MARKER = b"PWNED_42"

def judge_shell(out: bytes) -> Verdict: ...
def judge_flag(out: bytes) -> Verdict: ...
```

优先级（与现状一致）：`judge_flag` 先 `FLAG_RE`（真 flag），后 `NO_FILE_RE`（win reached）。
判定函数是**纯函数**，不做任何 I/O；I/O 留在 `run.py`（读多少、何时停）。

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 合并时语义漂移 → 基线掉 | 正则/常量逐字符复制；三套回归 + note 实打 |
| `FLAG_RE` 双重定义残留 | grep 全仓库确认只有 oracle 一处定义 |
| `win reached` cause 改变下游行为 | orchestrator 只读 `r.ok` / `r.note`，note 拼接格式不变 |
