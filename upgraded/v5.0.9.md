# v5.0.9 — 统一 verifier 主体切片（probe/spec 抽象）

> **状态**：🔄 进行中
> **Owner**：@Minzhi_Zhou

## 1. 背景

当前 shell 级成功判定已分成 `verify_shell` / `verify_shell_whoami` 两条路径，但命令、token、解析与 keep_alive 语义仍分散在函数内。

## 2. 目标

- 引入统一 verifier probe/spec 核心
- 保留现有 `verify_shell` / `verify_shell_whoami` 兼容入口
- 让后续 verifier 收敛可在不改调用方的前提下继续推进

## 3. 范围

- 更新 `upgraded.md`
- 更新 `v5_todo.md`
- 重构 `autopwn/core/shell_verify.py`
- 补充单元测试
- 不改 strategy 调用点

## 4. 风险

- probe 抽象与现有 keep_alive 语义不一致
- whoami 解析过严导致误拒绝
- 兼容入口命名漂移

## 5. 验收

- `verify_with_probe` 可驱动 `echo PWNED` 和 `whoami` 两类 probe
- 兼容包装函数行为保持不变
- 单测覆盖 generic probe 和既有 wrapper
- 文档 / 任务板同步

## 6. 记录

已完成 `VerifyProbe` / `verify_with_probe` 抽象，`verify_shell` 与 `verify_shell_whoami` 保持兼容；待推送上主干后再收尾为完成态。
