## 1. 背景 / 归类理由

`Challenge/canary` 的真实链路是 `fmtstr leak canary -> second gets BOF -> ret2hacked`。如果把需求写成“支持识别 `hacked` 函数”或“修 canary 题”，后续每遇到 `win/getflag/hack/backdoor/vuln/vulnerable` 命名变体，或者“先 leak 再 BOF”的题，都会继续堆单题补丁。真正的共性根因是：当前 `candidates(ctx)` 主要依赖 strategy 静态 priority + 粗粒度布尔条件，缺少对**候选目标函数**与**漏洞链路 evidence** 的显式建模。

## 2. 目标

在**不依赖 challenge-name 特判**的前提下，引入统一的目标函数候选打分与利用链排序，让 `fmtstr -> leak canary -> second-stage BOF`、`fmt write -> GOT hijack` 这类短链路优先于本地单进程下的盲目 canary 暴力。

## 3. 范围与非目标

**范围**：`autopwn/context.py`、`autopwn/recon/*`（新增目标候选收集模块）、`autopwn/detect/*`（新增 exploit hint 收集或在现有 detect 结果上补 hint）、`autopwn/exp/registry.py`、必要的 unit/integration tests，以及 `refactor.md` / `upgraded.md` 同步。

**非目标**：
- 不写 challenge-name 特判
- 不把关键词命中当成漏洞证明
- 不在本任务里顺手扩到 heap / blind pwn / 远程多轮交互

## 4. 实施方向

1. 在 `context.py` 增加 `FunctionCandidate` / `ExploitHint` 及其 `ctx.target_candidates` / `ctx.exploit_hints` / `ctx.preferred_target`
2. recon 层基于 symbol name、字符串引用、导入函数调用、xref 稀疏度、No PIE 可直达性收集目标函数候选
3. 名称关键词首版至少覆盖 `win/flag/getflag/print_flag/hack/hacked/backdoor/secret/admin/shell/pwn`，并补 `vuln/vulnerable` 作为**弱名称信号**；名称分只作 bonus，不得单独放行 strategy
4. detect 层显式产出链路 hint，如 `fmtstr_sink`、`second_input_sink`、`fmt_then_bof`、`canary_leakable`、`got_writable_no_pie`、`local_nonfork_canary_bruteforce_penalty`
5. `exp/registry.candidates(ctx)` 改为 `base priority + hint bonus - penalty` 的 effective priority 排序，但仍保留各 strategy 的硬前置条件 gate
6. stripped binary fail-closed：无符号时名称分降为 0，只允许 strings/imports/xref/protection 继续工作
7. detect 阶段对重复 `SIGABRT` / 明显无收益的动态溢出探测加 stop-loss，并快速回落到静态分析 / hint 路径，避免 `Challenge/canary` 这类题长时间刷本地进程
8. 首版评分常量与 guardrail 见 `refactor.md §3.2.4`，目标是“明显优于 challenge-name 热补丁”，不是一次到位的全自动最优

## 7. 风险

- 关键词库若权重过高，容易把普通辅助函数误判为 win/backdoor；必须设置名称分上限，并把 `vuln/vulnerable` 限制为弱加分
- registry 若只看分数不看硬前提，会出现“没 fmtstr 也去跑 fmtstr strategy”的越权排序；必须保留 `matches(ctx)` gate
- stripped binary 的 symbol 信息可能完全缺失，首版必须接受“只靠其他证据时保守失败”，不能为追求覆盖率退回 challenge 特判
- 若把 hint 逻辑散落进各 strategy，后续会再次碎片化；应尽量收敛在 context / recon / detect / registry 四层
