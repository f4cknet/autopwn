# v7.4.2c1 — 静态归因 + 静态事实提取

> 状态：✅ 已完成（2026-11-14；归因修正 + x64 `-static` 事实验证；C2 仍 ⏳）
> 父任务：[`v7.4.2`](./v7.4.2.md)；对应缺陷 C1（本轮），C2 见父任务 §6
> 验证方复核：目标样本 `static=True`、`bits=32`、`binsh=None`

## 1. 归因修正（`_audit_facts`）

| 条件 | 旧行为 | 新行为 |
|---|---|---|
| `plt_map` 为空、**非 static** | 「PLT 映射为空：桩形态未识别…」 | 不变 |
| `plt_map` 为空、**static**、无 vuln | 同上（误诊） | 「静态链接：无 PLT（正常）；symbol 直呼未定位到可溢出调用点」 |
| `plt_map` 为空、static、有 vuln | 仍报 PLT 为空 | 静默（事实已知，不是 Unknown） |

## 2. 静态事实（全部 gate 在 `ch.prot.static`，旧路径优先）

1. `_static_sym(ch, name)`：只认 `.text` 内的符号地址（`ch.var` + `_in_text`）。
2. `_find_wins`：`plt_map` 为空时补 `system/execve/execl/execv/execvp/popen` 与
   `open/fopen/openat/read/fread`、`puts/printf/write/fwrite/fputs` 的符号地址。
   **只扫描 main 及其两层内可达的函数**，避免把静态 libc 内部（如 `do_system`）
   误当 win；D 已收紧 shell 判据，不会把内部垃圾串判成 shell。
3. `_static_vulns(ch, d, entries)`：**仅当既有 `_static_vuln` 没找到 vuln 时启用**
   （`ch10_static32` 的现有路径优先级不变）。从 main 及一层直接被调函数里找对
   sink 符号（`gets/read/scanf/fgets/strcpy/…`）的直呼，用 `_derive_offset` 推偏移；
   不进入库函数体（按符号名停表）。
4. `_find_numeric_menu` 的 scanf 地址解析支持静态符号（`scanf` / `__isoc99_scanf`），
   让缺口 A 的判据在静态题也生效。

## 3. 不承诺

- 本轮**不做** `s_ret2syscall64`（64 位，不适用该题）。
- i386 static 且 `binsh=None` 的 `/bin/sh` 自构造登记为 `v7.4.2c2` ⏳。
- 若 `_static_vulns` 让既有 `s_ret2syscall_write` 具备输入
  （`f.vulns/main/writer/bss`），允许它自然尝试；不为它新增代码、不承诺成功。

## 4. 验收

- `bench/ch10_static32 --facts-only`：不再出现「PLT 映射为空」，vulns/wins 与改前一致或更完整。
- x64 `-static -no-pie` synthetic 程序：`_static_vulns` 能定位符号直呼的 sink（镜像无 `-m32` 交叉工具链）。
- 三套回归不低于基线。

## 5. 实施记录（2026-11-14）

### 改动

- `_audit_facts`：`not ch.plt_map` 拆 static / 非 static 两个分支（见 §1 表）。
- `_static_sym` / `_static_reachable` / `_static_vulns` / `_SINK_ALIASES` /
  `_STATIC_LIB_STOP`；`analyse` 在旧 `_static_vuln` 失败后才启用 `_static_vulns`。
- `_find_wins`：static 时补 system/execve/… 与 open/read/puts/write 符号地址，
  扫描范围限 main 两层内（`_static_reachable`）。
- `_find_numeric_menu` 的 scanf/输入地址解析补静态符号（`_static_sym`）。
- **PLT 别名修复（与 a 共享）**：输入调用地址集合改从 `ch.plt_map` 全收；
  静态分支不变。

### 验证

- `bench/ch10_static32 --facts-only`：`vulns: ['gets@0x80489f6 disp=15 off=45']`、
  `wins: []`、**无**「PLT 映射为空」；与改前一致（旧路径优先，未被新事实改写）。
- 三套回归：`bench` 13/15 —— `ch10_static32` 仍 `=> SHELL ret2sys_write`，
  失败项仍只有 `ch07_acae` / `ch14_easyheap`；`bench_extra` 6+1；`bench_sys` 4/4。
- `scripts/test/v742_vectors.py` C1 组 **6/6**（x64 `-static`）：
  `static=True`、`plt_map` 空、无 PLT 误诊、`analyse` 有 vuln、
  `_static_vulns` 命中 `fgets` 且 `offset is not None`、静态 `system("/bin/sh")` win 识别。
  （x64 `-static` 链接了镜像里的静态 glibc，证明 `_static_sym("system")` 可用。）
- 32 位形态未在合成向量覆盖（镜像无 32 位 crt / i386 libc.a，**未尝试 `-m32`**），
  由 `bench/ch10_static32` 兜底；该题 `bits=32 / static=True` 的归因已按表中第二行修正。

**不承诺**：C1 只修事实与归因，`binsh=None` 的 i386 static 题仍需 C2（⏳）才能打通；
真样本是否因此可解由验证方下轮盲测确认。
