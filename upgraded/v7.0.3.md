# v7.0.3 repeater 解锁：fmt 误报修复 + `_start` 推 main + canary-echo 泄漏策略

- **索引位置**：`upgraded.md §2`
- **状态**：✅
- **Owner**：@Minzhi_Zhou
- **预估 / 实际**：6h / 5h

## 1. 背景

`chellenges/repeater`（2021 年 stripped amd64 题）0 attempts FAILED。2026-11-14 复盘 + 手工打穿
（3/3 真拿 shell），查明三个堵点，全部是**通用规则**而非单题调参：

| 堵点 | 事实 | 修法 |
|---|---|---|
| ① stripped 无 `main` 符号 | `s_ret2libc` / `s_canary_fmt` 的 `if not main: return` 直接跳过 | `_start` 的 `lea rdi,[X]; call __libc_start_main` 推导 main，注入符号表 |
| ② `fmt=48` 误报 | 循环里 `puts(buf)` 的 `lea rax,[rbp-0x30]` 被 `_find_fmt` 记到后面 `printf("Do you want...")` 头上——printf 参数其实是常量串 | 验证 lea 的目标寄存器真的流向 printf 的 rdi；否则不算 fmt 漏洞 |
| ③ canary 挡路且泄不出 | `puts(buf)` 回显遇 canary 低字节 `\x00` 截断 | **41 字节盖掉 LSB**：回显越过 `\x00`，吐出 canary[1:8]，重组 `b"\x00" + leak7` |

手工链（同进程三阶段，已验证）：
1. `Send(b"A"*40 + b"B")` → puts 回显读 canary；
2. stage1 = 40A + canary + 假 rbp + `pop_rdi(puts@got); puts@plt; 重入 main 函数体`；
3. 算 libc base 后 stage2 = 40A + canary + 假 rbp + `ret; pop_rdi(binsh); system`。

三个坑已实测确认：重入点必须选**带 prologue 的函数体**（跳循环体时 rbp 是垃圾，退出时
canary 检查读 `[rbp-8]` 必 smash）；stage2 需插裸 `ret` 对齐（否则 `do_system` 内 SIGSEGV）；
canary 重装 LSB 在**前**（内存序 `00 XX…`）。

## 2. 目标

1. `_find_fmt` 不再把常量串参数记成 fmt 漏洞；
2. stripped 二进制能推导 `main`，现有 `s_ret2libc` / `s_canary_fmt` 无需改动即可吃上；
3. 新策略 `s_canary_echo`：用 canary-echo 泄漏 + 对齐重入打「canary + 回显函数」类题；
4. `repeater` 本地真拿 shell（`PWNED_42` 回显证据），登记 `bench/RESULTS.md`。

## 3. 范围

## 4. 设计要点

| 项 | 约定 |
|---|---|
| main 推导 | `_start` 内 `lea rdi,[imm]`（或 `mov edi,imm`）→ `call __libc_start_main@plt`：imm 即 main |
| fmt 误报修复 | `call printf` 前 8 条内找的 `lea rdi/rax` 必须是 printf 的**第一个参数**（amd64: lea 目标寄存器随后 `mov rdi,…` 或 lea 直接 rdi；i386: `mov [esp],…`）。找不到流向证据 → 返回 None |
| canary-echo 探测 | 发 `b"A"*(buf_size) + b"B"`（buf_size = -disp 到 canary 的距离）→ puts 回显中 `B` 后的 7 字节 |
| 重组 | `canary_mem = b"\x00" + leak7`（内存序 LSB 在前）；截断（回显含 `\n`）视为本轮失败换下一轮 |
| 重入点 | 漏洞函数的 `func_entry`（带 prologue），不是循环体 |
| 对齐 | stage2 在 `pop_rdi` 前插 `f.gadgets["ret"]` |
| 溢出窗口 | 每阶段 payload = pad + canary + 假 rbp + ROP ≤ read limit |

## 5. 风险

| 风险 | 缓解 |
|---|---|
| main 推导误报（lea rdi 是别的参数） | 仅认 `call __libc_start_main@plt` 紧邻前的 lea；推错最多多跑几个 plan，判定层兜底 |
| fmt 修复让 fmt=48 类真漏洞漏报 | 修复条件是「有 lea 流向证据才算」，真漏洞（lea 真喂 printf）不受影响；`bench` 全量回归验证 |
| canary 随机字节含 `\n`/`\x00` 截断泄漏 | 回显按 `\n` 切；缺 7 字节视为该轮失败，canary_fmt 同款 cand 循环 |
| echo 泄漏把 canary LSB 改成 B，退出必 smash | 每次泄漏用新进程；泄漏与利用同进程内进行（探测阶段不发退出指令） |
| 触碰 13/15 基线 | 新策略只在 canary + 回显结构同时成立时产出 plan；三套回归守门 |
