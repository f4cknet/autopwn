# v7.4.2b — 全局写 → 跳 win

> 状态：✅ 已完成（2026-11-14；synthetic 端到端 PWNED_42，三套回归持平）
> 父任务：[`v7.4.2`](./v7.4.2.md)；对应缺口 B（1 题）

## 1. 缺口

`gets/strcpy` 写全局缓冲区，同时存在 `system("/bin/sh")` win。`_audit_facts`
已经正确报出「写入目标是全局缓冲区」，但 `Facts` 没有可消费的事实，
所有策略都按「栈偏移」找溢出点 → 零计划。

## 2. 事实层（`facts.py`）

### 新增字段

| 字段 | 内容 |
|---|---|
| `Win.arg_addr: int = 0` | `_first_arg_string` 已返回的字符串地址，顺手记下（后续参数化 win 用） |
| `Facts.global_writes: [(buf, sink, call, limit)]` | `offset is None` 且 `_buf_is_global` 命中的写点；`limit` 可为 None |
| `Facts.global_calls: [(slot, call)]` | 可写槽上的间接调用：`call/jmp [abs]`、`call/jmp [rip+disp]`、`call/jmp reg`（回看 5 条 `mov reg,[…]`），槽位必须 `_looks_writable` |

### 归因

`global_writes` + shell win 存在、但没有 `(buf, slot)` 可用对时，
`f.unknowns["global_win"]` 写具体原因（没有槽 / 距离超出窗口），不静默。

## 3. 策略 `s_global_write_win`（插在 `s_ret2csu` 之后）

- 仅 `f.shell_win` 存在时产出；对每个 `global_write × global_call`：
  `0 < slot - buf <= min(limit or 0x400, 0x400)`。
- `payload = b"A"*gap + p(win.addr) + _term(sink)`：
  - `_pack_ok` 过滤坏字节（gets 的 `\n`、scanf 的空白）；
  - `strcpy/strcat/sprintf` 额外要求地址字节无 NUL（C 串会截断）。
- 套 `_prelude_variants` 菜单前缀；`tag=""` 走通用 `execute()` + `judge_shell`。
- **没有证据对就不产出 Plan，不猜**；成功仍必须是真执行命令（`PWNED_42` / `uid=`）。

## 4. 风险与边界

| 风险 | 缓解 |
|---|---|
| `strcpy(dst, 常量)` 被误当可控写 | 只在同时存在近距离间接调用槽时才产出；失败不产生假成功 |
| GOT 槽混入（partial RELRO 可写） | 属于真实可写槽，保留；距离排序后尝试；不改 oracle |
| 无栈偏移的题尝试数增加 | 每对只 1 次，且排在既有栈策略之后 |

## 5. 验收

- synthetic x64 程序（全局缓冲 + 全局函数指针 + `system("/bin/sh")`）：
  `global_writes/global_calls` 非空，策略存在且 payload 末字 = `win.addr`，
  端到端期望 `PWNED_42`。
- 三套回归不低于基线。

## 6. 实施记录（2026-11-14）

### 改动

- `facts.Win.arg_addr`；`Facts.global_writes / global_calls`；`_find_global_writes` /
  `_find_global_calls` / `_global_win_pairs`。
- `_buf_is_global` 增加 **x64 `lea reg, [rip+disp]`** 形态（x64 的非 PIE/PIE 产物

- `_audit_facts`：有全局写 + shell win 但无可用槽时写 `unknowns["global_win"]`。
- `cli.py`：`--facts-only` 打印 `global:`。
